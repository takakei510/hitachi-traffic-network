# Road Capacity Cascade

## 概要

既存の Node Capacity Cascade を残したまま、道路（エッジ）を故障対象とする独立モードです。

- 負荷: 道路長を重みとしたエッジ媒介中心性
- 容量: 初期負荷を道路長で補正
- 故障対象: 道路（エッジ）
- 再計算: 故障道路を削除した残存グラフ上で毎ステップ再計算

## 容量式

道路 `e` の容量は次で定義します。

```text
C_e = (1 + alpha) L_e(0) (length_e / mean_length)
```

- `L_e(0)`: 初期状態のエッジ媒介中心性
- `length_e`: 道路長
- `mean_length`: 対象グラフ内の平均道路長
- `alpha`: 容量の余裕

道路長は、車線数・道路幅・制限速度などの代わりに用いる代理指標です。実交通容量を直接表すものではありません。

## カスケードの流れ

1. 初期状態のエッジ媒介中心性を計算する
2. 各道路の容量を固定する
3. 初期故障道路を削除する（Step 0）
4. 残存ネットワーク上でエッジ媒介中心性を再計算する
5. `現在負荷 / 容量 > 1` の道路を同時に削除する
6. 新しい容量超過道路がなくなるまで繰り返す

## Streamlitでの使い方

```powershell
streamlit run app.py
```

左側のページ一覧から `Road Capacity Cascade` を開きます。

1. `alpha`、`seed`、初期故障道路の選び方を設定
2. 場所名を検索
3. 対象半径を選択
4. 初期故障道路を確認または選択
5. `Road Capacity Cascadeを実行` を押す
6. Stepスライダーで負荷率ヒートマップを切り替える

## 地図の色

- 青: 負荷率 0.0–0.4
- 緑: 負荷率 0.4–0.7
- 黄: 負荷率 0.7–0.9
- オレンジ: 負荷率 0.9–1.0
- 赤: 容量超過
- 黒: 初期故障道路
- 濃い赤: 現在ステップで故障した道路
- 薄い赤: 過去ステップで故障した道路

## 注意

このモードは複雑ネットワーク上の簡易モデルです。実際の交通量、OD需要、道路幅、車線数、信号、速度、時間帯、事故復旧などは扱っていません。
