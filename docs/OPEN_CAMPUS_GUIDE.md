# Open Campus Guide

## 説明の主軸

展示では、日立周辺の道路ネットワークに対して、どこを壊すと障害が連鎖するかを比較できることを示す。今回の実装では、場所名検索で中心地点を決め、その周辺だけを見ながらカスケード故障の結果を即時に確認できる。

## 見せ方

1. まず `streamlit run app.py` で画面を開く。
2. `日立駅` や `茨城大学日立キャンパス` を入力し、候補が複数なら一覧から選ぶ。
3. `500 m`、`1 km`、`2 km`、`3 km` を切り替えて、見える範囲がどう変わるかを見せる。
4. `地図クリック` または `候補ノード選択` で故障地点を決める。
5. 必要に応じて `部分グラフ` と `全体グラフ` を比較し、既定は部分グラフであることを示す。
6. `各 cascade_step を表示` を有効にして、段階ごとの変化を見せる。

## 現在のデモで伝える内容

- Streamlit 画面では、正常ノードは灰色、初期故障は黒、連鎖故障は赤、最大連結成分は青系で表示する。
- 検索地点には Google Maps へのリンクを表示し、API キーなしで開ける。
- UI は簡易モデルであり、実交通流の厳密再現ではないことを明示する。
- バッチ解析結果の比較や CSV/JSON/PNG 出力は従来どおり利用できる。
