# Open Campus Guide

## 説明の主軸

展示では、日立周辺の道路ネットワークに対して、どこを壊すと障害が連鎖するかを比較できることを示す。

## 見せ方

1. まず `python -m hitachi_network` で解析を実行できることを伝える。
2. ランダム故障と高負荷ノード故障の 2 条件を比較していることを示す。
3. 結果として CSV、JSON、PNG を保存できることを見せる。
4. PNG で残存ノード数の差を見せ、どちらの破壊が連鎖を起こしやすいかを説明する。

## 現在のデモで伝える内容

- CLI で一括実行できる。
- カスケード故障は負荷再計算と容量超過の繰り返しで進む。
- 高負荷ノードを優先的に攻撃すると、ランダム故障より大きな連鎖が起きやすい。
- 出力は `outputs/cascade_test/` のようなディレクトリにまとめられる。
